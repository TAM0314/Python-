# 弓道競技 的中率分析Webアプリ 開発計画

## 1. 目的と概要
弓道における的中率（的中数/射数）を記録・集計・分析し、個人の技量向上やチームの練習効率化を支援するWebアプリケーションを構築する。

## 2. 主な機能要件
- **練習記録の入力**:
  - 日付、場所、射種（立、巻藁など）、4射単位（例: 〇〇✕〇）での直感的な的中結果の記録。
- **的中率の可視化・分析**:
  - 全体および期間別（直近1週間、1ヶ月など）の的中率推移グラフ。
  - 射種ごとの的中率傾向分析。
  - 連続的中数（皆中など）の統計。
- **データ管理**:
  - ブラウザの `localStorage` によるデータの永続化。
  - CSV/JSONでのデータエクスポート・インポート機能。

## 3. 技術スタック
- **フロントエンド / バックエンド**: Next.js (React / TypeScript)
- **UI**: Tailwind CSS, shadcn/ui 
- **グラフ描画**: Recharts (または Chart.js)

## 4. 実装ステップ
1. **データモデル・状態管理の設計**:
   - 練習セッション・4射単位の的中データを定義するTypeScript型構造の作成。
2. **UIコンポーネントの実装**:
   - データ入力フォーム（4射単位の〇/✕選択・入力UI）。
   - ダッシュボード（的中率のサマリーカード、推移グラフ）。
3. **分析ロジックと永続化の実装**:
   - 期間別・射種別の的中率計算および `localStorage` 連携。
4. **検証**:
   - UIの動作確認、計算ロジックの確認。

## 5. 検証プラン
- ダッシュボードでのグラフ表示確認。
- データの追加・削除・集計値の正確性確認。
